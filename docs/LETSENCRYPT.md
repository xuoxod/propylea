# 🔒 Let's Encrypt TLS Integration & Automated Renewal

Propylea reads standard PEM-formatted X.509 certificate chains and private keys generated by ACME clients like **Certbot** or **acme.sh**.

---

## 🚀 Initial Certificate Acquisition

### Option 1: Standalone Certbot (Before Starting Propylea)
If Propylea is not yet running on port 80:

```bash
sudo certbot certonly --standalone \
  -d example.com \
  -d www.example.com \
  --email admin@example.com \
  --agree-tos --non-interactive
```

The certificates are generated at:
* Certificate chain: `/etc/letsencrypt/live/example.com/fullchain.pem`
* Private key: `/etc/letsencrypt/live/example.com/privkey.pem`

---

### Option 2: DNS-01 Challenge (Recommended for Wildcards & Multi-Domain)
DNS-01 verification proves domain ownership via DNS TXT records. It requires no open ports and works behind strict firewalls and NAT:

```bash
# Example with Cloudflare DNS plugin
sudo certbot certonly \
  --dns-cloudflare \
  --dns-cloudflare-credentials ~/.secrets/cloudflare.ini \
  -d example.com \
  -d "*.example.com"
```

---

## 🔑 Permissions Configuration

By default, Let's Encrypt sets `/etc/letsencrypt/archive` and `live` to permissions `0700` (root-only). If running Propylea under a dedicated non-root `propylea` service user:

```bash
# Grant the propylea group read access to certificates
sudo chgrp -R propylea /etc/letsencrypt/live /etc/letsencrypt/archive
sudo chmod 750 /etc/letsencrypt/live /etc/letsencrypt/archive
sudo chmod 640 /etc/letsencrypt/live/*/privkey.pem
```

---

## 🔄 Automated Zero-Downtime Renewal Hook

Certbot automatically runs renewal checks via systemd timers twice daily. When certificates are renewed, Propylea should be reloaded.

Create a deploy hook script at `/etc/letsencrypt/renewal-hooks/deploy/propylea-reload.sh`:

```bash
#!/bin/bash
set -e

# Verify new certificates before reloading
if /usr/local/bin/propylea check --config /etc/propylea/propylea.toml; then
    echo "[$(date)] Valid certs detected. Reloading Propylea..." >> /var/log/propylea-renewal.log
    systemctl restart propylea
else
    echo "[$(date)] CERT VALIDATION FAILED! Propylea not restarted." >> /var/log/propylea-renewal.log
    exit 1
fi
```

Make the hook executable:
```bash
sudo chmod +x /etc/letsencrypt/renewal-hooks/deploy/propylea-reload.sh
```

Test the renewal dry-run:
```bash
sudo certbot renew --dry-run
```
